# Word illustrations

One image per word, named after the note (`brittle.jpg`), referenced from the
note's frontmatter:

```yaml
image: "brittle.jpg"
image_alt: "A rigid ceramic rod snapping sharply under pressure"
```

Keep them small — 512px on the long edge is plenty for a vocabulary card, and
the whole folder is served from GitHub Pages alongside the site.

They can be drawn, photographed, taken from a source you are allowed to use, or
generated with `_System/Scripts/generate_images.py` in the vault.

**Not every word wants one.** A picture helps a concrete word (*brittle*,
*underdog*, *front-runner*) and does nothing for an abstract one (*necessitate*,
*infeasible*). An image that does not carry the meaning is decoration competing
with the definition for attention.
